# Majestik Envol

Site vitrine statique de Majestik Envol.

## Stack

- HTML5
- CSS3
- JavaScript vanilla

## Développement local

Ouvrir `index.html` dans un navigateur ou lancer un petit serveur local :

```bash
python3 -m http.server 8080
```

Puis ouvrir `http://localhost:8080`.
